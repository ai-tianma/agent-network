# agent-node — 排队项有归属，负责人离开时明确终止，v2.5.0-preview.153

共享会话忙的时候，任务以前是**沉默地**等满 30 分钟才报一句泛泛的「会话忙」。这一版让它说清两件事：**等的是谁的那条任务**，以及**共享会话的负责人真的走了**。

## 归属：等的是谁的那条任务

排队项在开始等的那一刻就绑定了 task id 与提交者，节点状态文本变成：

> 共享会话忙，任务还没提交，已等 3 分 20 秒（等 TUI 这轮结束；任务 5844f347 由 通信龙 提交）

看板上不止看得出「节点在等」，还看得出等谁。

## 终止：负责人离开时明确终止

共享会话的负责人（TUI）离开、而且会话也没了的时候（`GET /session/:id` 明确 404），排队中的任务被**明确终止**，理由 `owner_left`：

> opencode 任务未提交：共享会话的负责人（TUI）已经离开，会话也不在了 —— 排队中的任务 5844f347（由 通信龙 提交）已被明确终止（owner_left），不是节点卡死。这一轮没有发出，可稍后重发。

**判定要连续确认**：至少 3 次观测、且连续 2 秒 —— 一次 404 不算数，5xx 与超时一律重置计数继续等。**会话还在**就照常等它空闲后提交（重新提交那一半行为不变）。

**不变**：30 分钟硬预算不变，也没有改成排队池；等待期间的可见状态不变。

## Install

```bash
npm install -g @sleep2agi/agent-node@2.5.0-preview.153
```

用你要替换的那个节点同一份 Hub 与网络令牌，不要复制别的节点的 `config.json`。

## Upgrade

```bash
anet upgrade
```

或者把上面的版本装进这个节点自己的前缀，等它空闲时再重启这个节点。重启会丢掉该节点上正在进行的一轮对话。这一版不会替你重启任何节点。

停留在 2.5.0-preview.152 或更早的节点，行为保持原样：等待期间看不出是谁的那条任务，负责人离开也要等满预算才失败。
